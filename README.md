# Task 1 – Data Cleaning and Preprocessing

## Data Analyst Internship

### Objective
The objective of this task is to clean and preprocess a raw dataset using Microsoft Excel and prepare it for further analysis.

## Dataset
The dataset used for this task is `Raw_Dataset.xlsx`.

### Dataset Details
- Original Rows: 9,994
- Cleaned Rows: 9,994
- Columns: Same as the original dataset
- Duplicate Rows Found: 0
- Missing Values Found: 0
- Blank Rows Removed: 0
- Date Column: `Order_Date`

## Data Cleaning Steps Performed

1. Checked the dataset for missing values.
2. Checked the dataset for duplicate records.
3. Removed unnecessary blank rows, if any.
4. Standardized column headers.
5. Removed leading and trailing spaces from text values.
6. Standardized the `Order_Date` column.
7. Converted the date format to `dd-mm-yyyy`.
8. Checked the cleaned dataset for data quality.

## Excel Workbook Structure

The final Excel workbook contains three sheets:

### 1. Original Data
Contains the original raw dataset without modifications.

### 2. Cleaned Data
Contains the cleaned and standardized dataset prepared for analysis.

### 3. Project Summary
Contains a summary of the dataset and the cleaning steps performed.

## Tools Used

- Microsoft Excel
- GitHub

## Result

The dataset was successfully cleaned and prepared for further data analysis. No duplicate rows or missing values were found in the dataset. The `Order_Date` column was standardized to the `dd-mm-yyyy` format.
